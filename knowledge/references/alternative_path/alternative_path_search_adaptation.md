# 可选工艺路线 FJSP 搜索适配

可选工艺路线实例在普通机器分配与排序之上增加了一层路线选择。标准 FJSP 机制仍然有用，但如果不能显式改变和验证路线，就不完整。

## 构造方法族

构造阶段不得把路线选择当作事后补充。可靠流程为：

```text
路线优先或路线后悔值评分
-> 在当前起点或部分状态中为每个工件选择一条路线
-> 在选择路线形成的工序集合上执行工序级构造
-> 完整解码并验证所选路线
-> 以结构不同的路线选择执行多起点
```

兼容的路线信号包括：

- 路线加工工作量与瓶颈暴露程度；
- 路线长度和跳过工序节省量；
- 同一工件最优路线与次优路线之间的后悔值；
- 该路线工序集合在下游造成的机器拥塞。

路线选择会改变工序全集，因此多起点很重要。即使派工规则相同，采用不同路线选择的两个起点也可能在排序产生差异前就落入互不相交的吸引域。

## 耦合局部搜索方法族

启用路线选择后，纯机器顺序邻域并不充分。合法的耦合循环为：

```text
选择一个路线切换候选
-> 以事务方式重建所选工序集合
-> 完整重新解码
-> 与换机分配、插入或交换邻域组合
-> 仅在完整验证后接受
```

有效的路线切换锚点包括：

- 位于关键路径或近关键机器块上的工件；
- 其替代路线能够移除瓶颈工序的工件；
- 当前路线在某一机器族上造成长时间排队的工件。

路线切换是结构移动，不是元数据开关。改变一个工件的路线后，求解器必须重建预期工序集合，按新路线顺序重算前驱关系，并丢弃已移除工序的陈旧调度记录。

## 精确/混合方法族

精确通道必须显式建模路线选择。必需模式为：

- 每个工件-路线二元组使用一个布尔路线选择变量；
- 每个工件采用独热路线选择约束；
- 为工序-机器备选项建立可选区间；
- 使用条件存在性和条件前驱约束，使所选路线上的工序才处于激活状态；
- 普通机器 `NoOverlap` 只约束激活的加工区间。

这比把原始工序池中的所有工序都写入模型、寄希望于未使用工序保持空闲更严格。如果一道工序只属于未选择路线，就必须在调度中条件性缺席。

对大型实例，精确搜索更适合用作当前最优解附近的有界混合修复。只释放少量工件、路线变量和瓶颈附近的机器顺序决策，并证明真实运行证据：已添加的路线独热约束、非零可选区间数、求解器状态、求解时间和提取出的 `selected_routes`。

## 常见失败模式

- 路线在解析时固定一次，搜索过程从不重新考虑。
- 求解器输出 `selected_routes`，却仍为同一工件调度多条路线上的工序。
- 路线切换更新了 `selected_routes`，但被移除工序仍留在机器序列中。
- 精确模型建立了机器区间，却没有真正的路线独热约束或条件前驱约束。
- 验证只检查最终最大完工时间，不能证明搜索过程中强制满足所选路线覆盖。

当前基准是路线选择 FJSP，不是通用工艺规划图问题。适配范围应保持严格：每个工件恰好选择一条路线、只调度所选序列，并为所选方法族提供明确证据。
