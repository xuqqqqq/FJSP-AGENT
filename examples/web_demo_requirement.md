# 标准 FJSP 自演进演示需求文档

## 1. 问题目标

给定一个标准 Flexible Job-Shop Scheduling Problem（FJSP）算例，生成一个完整合法调度方案，使所有工件的所有工序都被安排到可选机器上，并尽量最小化最大完工时间（makespan）。

## 2. 硬约束

- 每个工件由若干道工序组成，同一工件内部必须满足工序先后顺序。
- 每道工序可以从候选机器集合中选择一台机器加工。
- 机器同一时间只能加工一道工序，不能发生重叠。
- 工序加工时间必须等于所选机器对应的加工时间。
- 解必须包含所有工序，不能遗漏或重复。

## 3. 优化目标

主要目标是最小化 makespan。若存在多个 makespan 相同或接近的方案，优先选择调度结构更稳定、规则更容易解释的方案。

## 4. 自演进要求

系统应从需求文档、IO 文档和算例出发，生成策略候选并执行若干轮循环：

1. 解析问题和输入输出协议。
2. 生成一组调度策略或策略参数。
3. 调用固定 solver 与 evaluator 执行实验。
4. 汇总 makespan、合法率和 gap。
5. 根据 evaluator 结果写出反思，并进入下一轮。

Evaluator 是唯一合法性和质量判定来源，模型自评不能替代 evaluator。
