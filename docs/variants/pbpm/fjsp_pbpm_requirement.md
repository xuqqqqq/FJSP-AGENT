# 并行组批加工 FJSP 求解需求

目标是在标准 FJSP 机器选择和工序前置约束上，同时决定 p-batch 机器的批次构成，并最小化 makespan。

## 硬约束

- 未声明为批处理机的机器一次加工一道工序。
- 批处理机的每个批次最多容纳声明容量个工件。
- 同一批次只能包含同一 `family_id` 的工件。
- 同批成员共享完全相同的加工开始和结束时刻。
- 批次加工时长等于成员在所选机器上的加工时长最大值。
- 每道工序恰好出现一次；工件内部前置关系仍以批次结束时刻传播。

主要目标为 makespan。`batch_count`、各类批约束违反数只用于合法性和诊断。
