# 多特性 FJSP-JPC-TST 求解需求

给定柔性作业车间实例，为每道工序选择一台候选机器并生成完整排程，最小化 makespan。

除标准 FJSP 的工件内工序顺序、候选机器和机器互斥外，必须同时满足：

1. `job_precedences` 中的每条 `[u, v]` 都是硬前置边，工件 `v` 的第一道工序必须等待工件 `u` 的最后一道工序完成。
2. 同工件相邻工序以及跨工件前置边都要加入两端所选机器之间的运输时间。
3. 每道工序加工前需要所选机器上的准备时间；准备活动占用机器，但输出 schedule 只记录加工区间。

本问题的跨工件前置不是软优先级目标，准备时间也不是序列相关换型矩阵。固定 evaluator 是唯一合法性和 makespan 判定来源。
