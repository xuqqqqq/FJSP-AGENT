# Re-entrant FJSP 需求

本变体描述每个 job 内一个连续工序段的重复加工。它不新增展开后的硬约束类型；解析器先展开路线，下游按标准 FJSP 的工序优先、候选机器、加工时间和机器互斥约束求解。

验收顺序：

1. 严格解析并展开每个 loop。
2. 输出覆盖每道展开工序且无重复。
3. 固定 evaluator 判定合法。
4. 在合法候选中最小化 makespan。

Agent 应获知原始与展开规模、loop body/repeat 和规模膨胀。搜索可以使用重复访问压力、瓶颈/关键路径、耦合局部搜索、population/memetic 或 CP-SAT/局部精确修复，但不得硬编码 benchmark 答案，也不得发明 IO 未声明的批处理、随机重工或任意路线约束。
