# 多特性 FJSP-JPC-TST 适配

## 必须同时成立的语义

1. 每个工件内部相邻工序满足 `start(next) >= end(prev) + transport(machine(prev), machine(next))`。
2. 每条跨工件边 `u -> v` 表示工件 `u` 是 `v` 的前置件；`v` 的首工序必须等待 `u` 的末工序完成并运输到目标机器。
3. 每道工序在所选机器上加工前需要自身的准备时间。准备时间占用机器，但不写入输出 schedule；若它是机器上的首道工序，则加工开始不得早于准备时长。
4. 本问题的 setup 只依赖当前工序、所选机器及其加工时长，不依赖机器前驱，因此不得实现为 SDST 矩阵。
5. 本问题的 job precedence 是硬 BOM 约束，不是 `fjsp_priority` 的软优先工件目标。

## 方法适配

- 构造搜索：维护工件内与跨工件联合就绪计数，按 `max(作业到达时刻, 机器可插入时刻+准备)` 放置。
- 耦合局部搜索：换机、重插或交换后必须联合重算运输、BOM 和机器准备，不允许局部时间平移绕过传播。
- 群体/模因：交叉和变异后的解码器是唯一合法性恢复入口；染色体不得缓存过期开始时间。
- 精确混合：CP-SAT 用可选区间表达机器选择；同机顺序弧加入后继准备时长；工件内和跨工件弧加入由两端机器选择决定的运输时长。

## 验收证据

- 必须报告三个激活计数及各自违反数。
- 必须由固定 evaluator 重算 makespan、运输、BOM 前置和准备时间。
- 只有实际导入并调用 OR-Tools、返回可行/最优状态且成功提取完整排程，才可声明 CP-SAT 已运行。
